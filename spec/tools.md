# 一、整体流程（固定 6 步，一步不多一步不少）

## 步骤 1：前端 → Node-BFF（发起 SSE 请求）

- 前端通过 `EventSource` 请求 BFF
- 携带参数：`userId、conversationId、message`

## 步骤 2：Node-BFF → Java（第一次请求：非流式）

- BFF **转发**给 Java
- **关闭流式**，只让 AI 判断：**是否需要调用工具**
- Java 调用 AI，返回结果：`需要 tool / 不需要`

## 步骤 3：Node-BFF 执行 Tools（Mock）

- 如果 AI **需要工具**
- BFF 直接执行**本地 Mock 工具**（查询用户/订单等）
- 得到工具结果

## 步骤 4：Node-BFF → Java（第二次请求：开启流式）

- BFF 把 **工具结果 + 历史消息** 发给 Java
- Java 调用 AI，**开启流式输出 SSE**

## 步骤 5：Java → 数据库（对话数据入库）

- Java 把**用户问题、AI 回答、工具调用记录**全部入库
- Java 持续推送流式流给 BFF

## 步骤 6：Node-BFF → 前端（转发 SSE 流）

- BFF 把 Java 的流**原封不动转发给前端**
- 前端实时渲染文字
